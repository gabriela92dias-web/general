## Objetivo

Este repositório está vazio/minimalista. Ao trabalhar aqui, mantenha as mudanças pequenas e diretamente ligadas à tarefa solicitada.

## Regras gerais

- Responda e escreva comunicação em **português**.
- Faça **alcance mínimo**: não refatore nem “melhore” por conveniência.
- Evite alterações paralelas não solicitadas.

## Estrutura esperada (quando aplicável)

- Arquivos estáticos do site/app: `public/`
  - Fontes: `public/fonts/`
- Scripts auxiliares: `scripts/`

## Como rodar scripts (Python)

Se forem adicionados scripts em `scripts/`, prefira rodar com:

```bash
python3 scripts/<script>.py
```

Se o script precisar de dependências, registre-as em `requirements.txt` (ou documente no próprio PR/commit, se o repositório ainda não tiver padrão).

## Git

- 1 commit por mudança lógica.
- Mensagens de commit descritivas e objetivas.
